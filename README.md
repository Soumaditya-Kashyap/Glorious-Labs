# Glorious Labs 🚀

Glorious Labs is a full-stack platform designed for virtual internship simulations, course catalogs, student workspaces, and certificate management.

---

## 🏗️ Project Structure

```
Glorious_Labs/
├── frontend/       # Next.js 15 Frontend (App Router, Tailwind CSS, TypeScript)
├── backend/        # Express.js / TypeScript Backend API & Database Services
└── README.md       # Project Overview & Setup Guide
```

---

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express.js, TypeScript, Supabase / PostgreSQL

---

## ⚡ Quick Start

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### 1. Setup Backend
```bash
cd backend
npm install
npm run dev
```

### 2. Setup Frontend
```bash
cd frontend
npm install
npm run dev
```

The frontend application will be running at `http://localhost:3000`.

---

## 📜 Features

- 🎓 **Catalog & Internships:** Explore and apply for domain-specific internship modules.
- 💻 **Student Workspace:** Interactive environment for completing assignments and tasks.
- 📜 **Certificate Issuance:** Verified certificates upon successful completion.
- 🛡️ **Admin Portal:** Manage students, tracks, and platform metrics.
